# Data instructions

`data/sample/` contains **synthetic demonstration records** created for testing the project. They are not real job vacancies and must not be represented as a real-world employment dataset.

For a fuller academic experiment, download resume-category and job-listing datasets from sources such as Kaggle only after checking each dataset's license and terms. Store originals in `data/raw/` (ignored by Git), document the source and license, and update the loader to map the fields. Never commit personal resumes or sensitive information.

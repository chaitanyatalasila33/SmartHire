# SmartHire — Project Report

## Abstract

SmartHire is a classical machine-learning prototype that explores resume category prediction, content-based job recommendation, and skill-gap reporting. It combines a TF-IDF text representation, a Logistic Regression classifier, cosine-similarity ranking, and a keyword-based skill comparison module in a Streamlit interface.

## Problem statement

Students and early-career candidates may find it difficult to identify roles that align with their current skills. SmartHire demonstrates a lightweight tool that compares resume text with a local job corpus and surfaces possible matches and missing listed skills.

## Objectives

- Predict a broad job domain from resume text.
- Rank local job records by textual relevance.
- Compare resume skills with skills listed for a recommended role.
- Provide an interactive web demo and reproducible evaluation workflow.

## System design

Resume text is extracted from PDF, DOCX, or TXT input. The classifier applies TF-IDF features and Logistic Regression to predict a category. The recommender vectorizes each job's title, skills, and description, then computes cosine similarity against the resume. The skill-gap component compares terms found in the resume with terms listed for the top-ranked job. Streamlit presents the outputs.

## Data

The repository's built-in records are synthetic demonstration examples created for software testing. They are not a representative real-world dataset and do not constitute real vacancies. Before claiming real-world performance, the project must be evaluated on properly licensed public datasets with documented provenance and a representative held-out test set.

## Evaluation

Run `python scripts/train.py` to generate `reports/evaluation.json`. The script calculates accuracy, a classification report, and a confusion matrix using a deterministic stratified split of the synthetic examples. No performance value is asserted in this report because it should be generated by executing the script in the target environment. Results from this tiny dataset are illustrative only.

## Limitations

- Small synthetic dataset; no evidence of generalization to real resumes.
- Keyword-based skills may miss synonyms and context.
- Similarity score is not a probability of being hired.
- The local job corpus does not contain live vacancies.
- Scanned PDFs and OCR are not supported.

## Future work

- Replace demo records with licensed public datasets and record their provenance.
- Compare multiple classifiers using cross-validation and per-class metrics.
- Evaluate recommendations with human relevance judgments and Precision@K.
- Add skill synonym normalization and more robust parsing.
- Add deployment after local tests and privacy review.

## Conclusion

SmartHire provides a runnable educational demonstration of supervised text classification and unsupervised content-based recommendation. Its output should be treated as exploratory until validated on appropriate real-world data.
